# 해아림한의원 안양점 웹사이트 제작 매뉴얼 (Development Manual)

본 문서는 **해아림한의원 안양점(web-a)** 공식 웹사이트의 설계 구조, 디자인 시스템, 프론트엔드 아키텍처, 컴포넌트 명세 및 유지보수 가이드를 정리한 기술 매뉴얼입니다.

---

## 📌 1. 프로젝트 개요

- **프로젝트명**: 해아림한의원 안양점 공식 웹사이트 (`web-a`)
- **타겟 도메인**: 신경정신과(틱장애, ADHD, 공황, 불안, 강박, 불면, 자율신경실조증), 소아청소년 클리닉
- **대표원장**: 유종민 (한방내과 전문의 & 상담심리학 박사)
- **리포지터리**: `https://github.com/hearimay-cell/web-a.git`
- **주요 목적**: 
  - 신뢰감 있고 따뜻한 프리미엄 한의학 웹 경험 제공
  - 네이버 예약, 카카오톡 1:1 상담, 전화 문의 등 전환율(Conversion Rate) 극대화
  - 질환별 상세 정보 및 유튜브/블로그 미디어 콘텐츠 실시간 전달

---

## 🛠 2. 기술 스택 & 라이브러리

| 구분 | 기술 / 라이브러리 | 용도 / 특징 |
| :--- | :--- | :--- |
| **Core** | `HTML5`, `Vanilla JavaScript (ES6+)` | 경량성, 빠른 로딩 속도, 프레임워크 의존성 없는 유지보수성 |
| **Styling** | `Tailwind CSS (v3 CDN)` | 유틸리티 기반 반응형 UI 구성, 글래스모피즘, 커스텀 컬러 시스템 |
| **Typography** | `Pretendard Variable Font` | 고품질 한글 웹 폰트 (가독성 및 심미성 최적화) |
| **Iconography** | `Lucide Icons (CDN)` | 모던하고 일관된 벡터 라인 아이콘 |
| **Media Assets** | `WebP/PNG`, `SVG` | 무손실/고압축 이미지 및 크기 최적화 |

## 🎨 3. 디자인 시스템 & 가이드라인

### 3.1 브랜드 컬러 팔레트 (Brand Colors)
- **Main Brand Teal (메인 브랜드 딥 청록)**: `#087F78` / `teal-700` (`#0f766e`)
  - 신뢰감과 전문성을 상징하며 메인 CTA 버튼, 주요 헤드라인, 액센트 포인트에 사용
- **Sub Muted Yellow (서브 뮤트 옐로우)**: `#F5D96B` (텍스트: `#263238`)
  - 카카오톡 상담 배너 및 따뜻한 조화감을 주는 보조 CTA 컬러
- **Naver Green (네이버 그린)**: `#03C75A`
  - 네이버 예약, 블로그, 카페 배너에 적용
- **Background Tones**:
  - `bg-[#F7F7F6]` (메인 히어로 수묵화 톤)
  - `bg-white` & `bg-slate-50` (콘텐츠 카드 및 섹션 구분)
  - `bg-toss-black` (`#101828`) (하단 푸터 및 다크 액센트)

### 3.2 타이포그래피 규칙
- 기본 폰트: `Pretendard, -apple-system, BlinkMacSystemFont, system-ui, sans-serif`
- 헤드라인 폰트 웨이트: `font-black` (900), `font-extrabold` (800)
- 본문 폰트 웨이트: `font-medium` (500), `font-normal` (400)
- 자간 및 행간: `tracking-tight`, `leading-relaxed`

## 🧱 4. 섹션별 구조 & 컴포넌트 명세

### 4.1 상단 네비게이션 헤더 (`<header>`)
- **글래스모피즘 (`glass-nav`)**: 스크롤 시 반투명 블러 백드롭 적용
- **메뉴 구성**: 인사말, 특화진료, 검사진단, 의료진, 미디어, 오시는길
- **CTA 버튼**: 네이버 예약 바로가기 링크 연동

### 4.2 메인 히어로 배너 (`<section class="relative ...">`)
- **배경**: `assets/hero_bg.png` (한국 전통 수묵화 산수·연꽃 화병 배경)
- **타이틀**: `"증상 너머의 삶, 치유의 여정을 함께합니다"`
- **CTA 버튼 2종**:
  - `[네이버 1:1 맞춤 예약하기]` : `bg-[#087F78]` (딥 청록)
  - `[카카오톡 안양점 상담]` : `bg-[#F5D96B]` (뮤트 옐로우)

### 4.3 대표원장 인사말 (`#greeting`)
- **좌측**: 유종민 대표원장 프로필 사진 (`assets/director_yu.png`) + 대형 자격 태그(`한방내과 전문의·상담심리학 박사`)
- **우측**: 2배 확대된 큼직한 `인사말` 태그 배지 + 전문 진료 철학 본문

### 4.4 대표원장 약력 및 치료철학 (`#doctor`)
- **좌측 카드**: 학력 및 전문 자격 (경희대 한의학, 경희의료원 전문의, 심리학 석·박사)
- **우측 카드**: 3대 치료 철학 및 신체적 토대·두뇌 조절력 통합 진료 모델

### 4.5 9대 중점 특화 진료 (`#specialty`)
- 틱장애, 뚜렛증후군, ADHD, 강박증, 불안/공황장애, 우울/화병, 불면증, 자율신경실조증, 수험생클리닉
- 카드 클릭 시 **인포그래픽 상세 모달(`diseaseModal`)** 팝업 연동

### 4.6 6단계 정밀 진단 시스템 (`#process`)
- 사전설문 ➔ 뇌기능·자율신경 검사 ➔ 1:1 심층상담 ➔ 맞춤처방 ➔ 통합치료 ➔ 사후관리

### 4.7 미디어 & 칼럼 보드 (`#media`)
- **언론보도 & 기사 칼럼 10선 (기본 활성 탭)**:
  - 월간암, 메디컬투데이, 베이비뉴스, 동아일보 등에 게재된 유종민 대표원장의 전문 의학 칼럼 및 언론보도 10건 수록
  - **초기 6개 노출 및 페이지네이션 (`1/2` 페이지 및 `칼럼 더 보기/접기`)** 지원:
    - 1페이지: 1~6번 칼럼 표시 (기본값)
    - 2페이지: 7~10번 칼럼 표시
    - `칼럼 4개 더 보기` 버튼: 10개 전체 확장 표시 및 `접기 (6개만 보기)` 토글 제공
  - 질환 카테고리 태그, 언론사명, 게재일, 요약문, 썸네일 및 원문 기사 원클릭 링크(`target="_blank"`) 지원
- **유튜브 공식 영상 탭**:
  - 해아림 공식 유튜브 채널 최신 영상 목록 및 원내 비디오 재생 모달 연동
  - 공식 유튜브 채널 바로가기 버튼 제공
- **네이버 블로그 칼럼 탭**:
  - 해아림 네이버 공식 블로그 연재 칼럼 및 원문 보기 링크 연동
  - 공식 블로그 바로가기 버튼 제공

## 💻 5. 로컬 개발 및 파일 동기화 규칙

### 5.1 파일 동기화 원칙 (중요)
- 본 프로젝트는 `index.html`과 원본 소스 `ai_studio_code (10).html`을 100% 동일하게 유지합니다.
- `index.html` 수정 후 반드시 아래 명령어로 동기화합니다:
```powershell
Copy-Item "index.html" "ai_studio_code (10).html" -Force
```

### 5.2 로컬 서버 구동
```powershell
# Python HTTP Server 구동 (포트 3000)
python -m http.server 3000
```
- 접속 주소: `http://localhost:3000`
