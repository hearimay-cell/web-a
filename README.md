# 해아림한의원 안양점 웹사이트 (web-a)

자율신경·뇌신경·심리·소아청소년 클리닉 **해아림한의원 안양점** 공식 웹사이트입니다.

---

## 🚀 빠른 시작

### 1. 로컬 서버 실행

```bash
# Python 내장 웹 서버 실행 (포트 3000)
python -m http.server 3000

# 또는 npx serve 사용
npx serve .
```

브라우저에서 [http://localhost:3000](http://localhost:3000)으로 접속하여 확인하실 수 있습니다.

## 🌟 주요 구현 기능

1. **메인 히어로 배너**: 품격 있는 전통 수묵화 배경 & 딥 청록/뮤트 옐로우 CTA 버튼
2. **대표원장 인사말 & 프로필**: 유종민 대표원장 인물 사진, 인사말 및 전문 약력·치료철학
3. **9대 중점 특화 진료 과목**: 질환별 상세 인포그래픽 모달
4. **6단계 정밀 진단·검사 시스템**: 내원에서 검사·진단까지 체계적인 프로세스 안내
5. **네이버 실시간 예약 & 카카오톡 상담 연동**: 원클릭 간편 예약 시스템
6. **우측 고정 플로팅 퀵 사이드바**: 네이버예약, 카톡, 유튜브, 인스타, 블로그, 카페 바로가기
7. **모바일 최적화 반응형 레이아웃**: 하단 플로팅 퀵 바 & 터치 즉시 통화 연결 (`031-382-8885`)
